# Landing Hero Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a 14-second seamless muted video loop that plays full-bleed behind the Ochre Eights landing hero copy.

**Architecture:** The loop is authored as a deterministic HTML/CSS stage driven by a pure frame-math module — `frameState(f)` returns every element's position, rotation, and opacity for frame `f`, with no CSS animations and no wall-clock time. A headless browser seeks to each of the 336 frames and screenshots it; ffmpeg encodes the PNG sequence to WebM and MP4. Because the math takes `f` modulo 336, the seam is exact by construction, and the pure module can be unit-tested without a browser.

**Tech Stack:** Plain ESM (no framework) for the loop math, Python Playwright for frame capture, ffmpeg 7.1 for encoding and pixel analysis, vitest for tests, React 19 + Vite for the landing integration.

## Spec amendment — read before starting

The spec's **Generation** section assumes a generative-video tool driven by a "master prompt" and "per-phase motion prompts". That capability does not exist in this toolchain: the `DesignSync` tool reads and writes design-system *files* (HTML/CSS components) and cannot generate video.

This plan replaces that section with the approach the repo already uses for every other Ochre Eights artifact — an authored animated prototype in `design/` (compare `design/Ochre Eights - Animated Table.dc.html`), captured to video locally. Everything else in the spec stands unchanged: composition, palette, beat timings, loop-closure constraint, delivery formats, and success criteria are all implemented literally.

Task 7 updates the spec's Generation section to match. Do not skip it — leaving the spec describing a non-existent pipeline is how the next person wastes a day.

## Global Constraints

- Canvas 1920×1080, 24 fps, exactly 336 frames; frame 336 is identical to frame 0.
- Palette, verbatim: ground `#f5ead8`, surface `#ebddc5`, accent `#c67139`, ink `#201e1d`, red `#c23b2e`, yellow `#e0a020`, green `#66923f`, blue `#2e6f8a`.
- No text, no logos, no brand marks rendered inside the video. All copy stays in HTML.
- The video is muted and carries no audio stream at all (`-an` on every encode).
- Encoded WebM must be ≤ 4 MB. The MP4 fallback may exceed it only if WebM is under; both are checked.
- Copy-safe rectangle: no foreground card may overlap x ∈ [80, 700], y ∈ [300, 800] in 1920×1080 space, at any frame.
- Every animated quantity must be either a sine/cosine with an integer cycle count over 336 frames, or zero outside a window that does not touch the loop boundary.

```js
import { describe, it, expect } from 'vitest';
import { TOTAL, FPS, FAN, COPY_SAFE, frameState } from '../src/loop.mjs';

const frames = () => Array.from({ length: TOTAL }, (_, f) => frameState(f));

// Flatten a state into a list of comparable numbers, in a stable order.
function flatten(s) {
  const out = [];
  for (const b of s.blobs) out.push(b.x, b.y);
  out.push(s.glimpse.dot);
  for (const c of s.cards) out.push(c.x, c.y, c.rot, c.opacity);
  out.push(s.sailer.x, s.sailer.y, s.sailer.opacity);
  out.push(s.plus4.x, s.plus4.y, s.plus4.rot, s.plus4.scale, s.plus4.opacity);
  out.push(s.shock.r, s.shock.opacity, s.ripple.r, s.ripple.opacity);
  for (const p of s.penalties) out.push(p.x, p.y, p.rot, p.opacity);
  return out;
}

function maxDelta(a, b) {
  const fa = flatten(a), fb = flatten(b);
  let m = 0;
  for (let i = 0; i < fa.length; i++) m = Math.max(m, Math.abs(fa[i] - fb[i]));
  return m;
}

describe('loop geometry', () => {
  it('is 336 frames at 24fps, i.e. 14 seconds', () => {
    expect(TOTAL).toBe(336);
    expect(FPS).toBe(24);
    expect(TOTAL / FPS).toBe(14);
  });

  it('has five fan cards', () => {
    expect(FAN).toHaveLength(5);
  });
});

describe('loop closure', () => {
  it('frame 336 is identical to frame 0', () => {
    expect(flatten(frameState(TOTAL))).toEqual(flatten(frameState(0)));
  });

  it('handles negative and multi-cycle frame indices', () => {
    expect(flatten(frameState(-1))).toEqual(flatten(frameState(TOTAL - 1)));
    expect(flatten(frameState(TOTAL * 3 + 7))).toEqual(flatten(frameState(7)));
  });

  // The real seam test: modulo guarantees 336 === 0, but the step from the
  // last frame into the first must be no larger than a typical in-loop step,
  // or the loop visibly jerks once per cycle.
  it('does not jerk across the seam', () => {
    const all = frames();
    let typical = 0;
    for (let f = 1; f < TOTAL; f++) typical = Math.max(typical, maxDelta(all[f - 1], all[f]));
    const seam = maxDelta(all[TOTAL - 1], all[0]);
    expect(seam).toBeLessThanOrEqual(typical * 1.5);
  });

  it('is continuous everywhere, with no element popping in', () => {
    const all = frames();
    for (let f = 1; f < TOTAL; f++) {
      // 40 units covers the fastest intended motion (the +4 arc) with headroom.
      expect(maxDelta(all[f - 1], all[f])).toBeLessThan(40);
    }
  });
});

describe('copy legibility', () => {
  const CARD_W = 150, CARD_H = 220;
  const overlapsCopy = (o) =>
    o.x < COPY_SAFE.x + COPY_SAFE.w && o.x + CARD_W > COPY_SAFE.x &&
    o.y < COPY_SAFE.y + COPY_SAFE.h && o.y + CARD_H > COPY_SAFE.y;

  it('never puts a fan card over the copy-safe rectangle', () => {
    for (const s of frames()) {
      for (const c of s.cards) {
        if (c.opacity === 0) continue;
        expect(overlapsCopy(c)).toBe(false);
      }
    }
  });

  it('never puts the +4 over the copy-safe rectangle while visible', () => {
    for (const s of frames()) {
      if (s.plus4.opacity === 0) continue;
      expect(overlapsCopy(s.plus4)).toBe(false);
    }
  });
});

describe('beat timing, per the storyboard', () => {
  it('keeps the +4 invisible during the idle phase (before 6.0s)', () => {
    for (let f = 0; f < 6.0 * FPS; f++) expect(frameState(f).plus4.opacity).toBe(0);
  });

  it('slams the +4 down by 6.4s', () => {
    expect(frameState(Math.round(6.4 * FPS)).plus4.opacity).toBeGreaterThan(0.9);
  });

  it('fires the shockwave only after the slam', () => {
    expect(frameState(Math.round(6.0 * FPS)).shock.opacity).toBe(0);
    expect(frameState(Math.round(6.6 * FPS)).shock.opacity).toBeGreaterThan(0);
  });

  it('is back to the resting pose by the end of the loop', () => {
    const end = frameState(TOTAL - 1), start = frameState(0);
    expect(end.plus4.opacity).toBe(0);
    expect(end.shock.opacity).toBe(0);
    expect(end.ripple.opacity).toBe(0);
    for (let i = 0; i < FAN.length; i++) {
      expect(Math.abs(end.cards[i].rot - start.cards[i].rot)).toBeLessThan(2);
    }
  });
});
```

Create `tools/hero-loop/src/loop.mjs`:

```js
export const TOTAL = 336;
export const FPS = 24;
const TAU = Math.PI * 2;

export const PALETTE = {
  ground: '#f5ead8', surface: '#ebddc5', accent: '#c67139', ink: '#201e1d',
  red: '#c23b2e', yellow: '#e0a020', green: '#66923f', blue: '#2e6f8a',
};

// Hero copy sits left; nothing in the foreground may cover this rectangle.
export const COPY_SAFE = { x: 80, y: 300, w: 620, h: 500 };

// Resting fan, center-right of a 1920x1080 frame. Card art is 150x220.
export const FAN = [
  { id: 'red7',    suit: 'red',    label: '7', x: 1120, y: 520, rot: -13, cycles: 3, amp: 10, phase: 0.00 },
  { id: 'yellow3', suit: 'yellow', label: '3', x: 1258, y: 496, rot:  -5, cycles: 4, amp: 12, phase: 0.20 },
  { id: 'green',   suit: 'green',  label: 'S', x: 1396, y: 488, rot:   3, cycles: 5, amp:  9, phase: 0.55 },
  { id: 'blue5',   suit: 'blue',   label: '5', x: 1534, y: 500, rot:  11, cycles: 6, amp: 11, phase: 0.85 },
  { id: 'back',    suit: 'back',   label: '',  x: 1672, y: 524, rot:  19, cycles: 7, amp:  8, phase: 1.30 },
];

// --- periodic primitives -------------------------------------------------
// Shortest distance between two frames on the loop's circle.
export function wrapDist(f, center) {
  const d = Math.abs(f - center) % TOTAL;
  return Math.min(d, TOTAL - d);
}

// Smooth 1-at-center bump, exactly 0 once |dist| >= radius.
export function bump(f, center, radius) {
  const d = wrapDist(f, center);
  if (d >= radius) return 0;
  return Math.cos((Math.PI / 2) * (d / radius)) ** 2;
}

// Smoothstep ramp, clamped: exactly 0 at or before start, exactly 1 at or after end.
export function ramp(f, start, end) {
  if (f <= start) return 0;
  if (f >= end) return 1;
  const x = (f - start) / (end - start);
  return x * x * (3 - 2 * x);
}

// Rise then fall; exactly 0 outside (start, end).
export function pulse(f, start, peak, end) {
  if (f <= start || f >= end) return 0;
  return f < peak ? ramp(f, start, peak) : 1 - ramp(f, peak, end);
}

// --- beat timings, in frames (see the spec's beat table) -----------------
const CONSIDER = 60;    // 2.5s  the yellow card lifts
const SAIL     = 108;   // 4.5s  a card back crosses the background
const ENTER    = 144;   // 6.0s  the +4 enters
const SLAM     = 154;   // 6.4s  the +4 lands
const RIPPLE_0 = 163;   // 6.8s  four-colour ripple begins
const SHOCK_1  = 192;   // 8.0s  shockwave and ripple gone
const EXHALE   = 216;   // 9.0s  glow faded, resettle begins
const SETTLED  = 276;   // 11.5s everything back in formation

export function frameState(f) {
  // Modulo first: this is what makes frame 336 identical to frame 0.
  const ff = ((f % TOTAL) + TOTAL) % TOTAL;
  const th = TAU * (ff / TOTAL);

  // Ground: two blobs, exactly one drift cycle per loop.
  const blobs = [
    { x: 1680 + 40 * Math.cos(th),        y: -60 + 26 * Math.sin(th) },
    { x: -110 + 32 * Math.cos(th + 2.1),  y: 820 + 34 * Math.sin(th + 2.1) },
  ];

  // Mid-depth: the table glimpse's live dot breathes twice per loop.
  const glimpse = { dot: 0.45 + 0.25 * Math.sin(TAU * 2 * (ff / TOTAL)) };

  // Phase II envelopes.
  const consider = bump(ff, CONSIDER, 34);          // the "hmm" lift
  const scatter  = pulse(ff, SLAM, SLAM + 4, SETTLED);
  const shockE   = pulse(ff, SLAM, SLAM + 6, SHOCK_1);
  const rippleE  = pulse(ff, RIPPLE_0, RIPPLE_0 + 14, SHOCK_1);

  const cards = FAN.map((c, i) => {
    const bob = c.amp * Math.sin(TAU * c.cycles * (ff / TOTAL) + c.phase);
    // Scatter pushes cards outward from the fan's centre card (index 2).
    const dir = i - 2;
    const lift = c.id === 'yellow3' ? -20 * consider : 0;
    return {
      id: c.id,
      x: c.x + dir * 26 * scatter,
      y: c.y + bob + lift - 8 * scatter,
      rot: c.rot + dir * 4 * consider + dir * 6 * scatter,
      opacity: 1,
    };
  });

  // Background card back sailing left to right; invisible outside its window.
  const sailE = pulse(ff, SAIL - 44, SAIL, SAIL + 44);
  const sailer = sailE === 0
    ? { x: 700, y: 250, opacity: 0 }
    : { x: 700 + 520 * ramp(ff, SAIL - 44, SAIL + 44), y: 250, opacity: 0.35 * sailE };

  // The +4: arcs in, slams, then slides under the fan and out.
  const enterP = ramp(ff, ENTER, SLAM);
  const exitP  = ramp(ff, EXHALE, SETTLED);
  const visible = ff > ENTER && ff < SETTLED;
  const plus4 = !visible
    ? { x: 1180, y: 470, rot: 0, scale: 1, opacity: 0 }
    : {
        x: 1720 - 540 * enterP + 60 * exitP,
        y: 120 + 350 * enterP + 40 * exitP,
        rot: 26 - 26 * enterP,
        // One-frame pop on landing, then settle.
        scale: 1 + 0.10 * pulse(ff, SLAM - 1, SLAM, SLAM + 5),
        opacity: 1 - exitP,
      };

  const shock  = { r: 40 + 300 * ramp(ff, SLAM, SHOCK_1), opacity: 0.55 * shockE };
  const ripple = { r: 80 + 420 * ramp(ff, RIPPLE_0, SHOCK_1), opacity: 0.30 * rippleE };

  // Two penalty cards arc up and tumble back down behind the fan.
  const penalties = [0, 1].map((n) => {
    const s = RIPPLE_0 + n * 8;
    const e = s + 53;
    const p = pulse(ff, s, s + 26, e);
    if (p === 0) return { x: 1300, y: 900, rot: 0, opacity: 0 };
    const t = ramp(ff, s, e);
    return {
      x: 1240 + n * 190 + 120 * t,
      y: 900 - 420 * Math.sin(Math.PI * t),
      rot: 360 * t * (n ? -1 : 1),
      opacity: 0.5 * p,
    };
  });

  return { blobs, glimpse, cards, sailer, plus4, shock, ripple, penalties };
}
```

```python
"""Screenshot every frame of the hero loop stage.

Deterministic by construction: the page runs no CSS animations and no timers,
so a screenshot of frame N is identical on every run.
"""
import pathlib
import shutil
import sys

from playwright.sync_api import sync_playwright

URL = "http://localhost:8899/design/hero-loop/render.html"
OUT = pathlib.Path(__file__).parent / "frames"


def main() -> int:
    if OUT.exists():
        shutil.rmtree(OUT)
    OUT.mkdir(parents=True)

    with sync_playwright() as p:
        browser = p.chromium.launch(channel="chrome")
        page = browser.new_page(viewport={"width": 1920, "height": 1080},
                                device_scale_factor=1)
        page.goto(URL)
        page.wait_for_function("window.__ready === true", timeout=15000)
        total = page.evaluate("window.__total")

        for f in range(total):
            page.evaluate(f"window.__seek({f})")
            page.screenshot(path=str(OUT / f"{f:04d}.png"))
            if f % 48 == 0:
                print(f"  frame {f}/{total}", flush=True)

        # One extra render of frame `total` proves the seam at pixel level.
        page.evaluate(f"window.__seek({total})")
        page.screenshot(path=str(OUT / "seam.png"))
        browser.close()

    print(f"captured {total} frames to {OUT}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```bash
#!/usr/bin/env bash
# Encode the captured PNG sequence to the two web formats plus a poster.
# Run from the repo root: bash tools/hero-loop/encode.sh
set -euo pipefail

FRAMES="tools/hero-loop/frames"
OUT="client/public/hero"
mkdir -p "$OUT"

# WebM (VP9) — the primary asset, budgeted at 4 MB.
ffmpeg -y -loglevel error -framerate 24 -i "$FRAMES/%04d.png" \
  -c:v libvpx-vp9 -crf 34 -b:v 0 -row-mt 1 -pix_fmt yuv420p -an \
  "$OUT/loop.webm"

# MP4 (H.264) — the Safari and older-browser fallback.
ffmpeg -y -loglevel error -framerate 24 -i "$FRAMES/%04d.png" \
  -c:v libx264 -crf 24 -preset slow -pix_fmt yuv420p -movflags +faststart -an \
  "$OUT/loop.mp4"

# Poster: frame 0, which is also the loop's resting pose, so a paused or
# not-yet-loaded video is indistinguishable from a playing one.
ffmpeg -y -loglevel error -i "$FRAMES/0000.png" -quality 82 "$OUT/loop-poster.webp"

ls -lh "$OUT"
```

```js
import { describe, it, expect } from 'vitest';
import { execFileSync } from 'node:child_process';
import { existsSync, statSync } from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { COPY_SAFE, TOTAL } from '../src/loop.mjs';

const here = path.dirname(fileURLToPath(import.meta.url));
const ROOT = path.resolve(here, '../../..');
const FRAMES = path.join(here, '..', 'frames');
const ASSETS = path.join(ROOT, 'client/public/hero');

const pad = (n) => String(n).padStart(4, '0') + '.png';
const haveFrames = existsSync(path.join(FRAMES, pad(0)));
const haveAssets = existsSync(path.join(ASSETS, 'loop.webm'));

function ffprobe(file, entries) {
  return execFileSync('ffprobe', [
    '-v', 'error', '-select_streams', 'v:0',
    '-show_entries', entries, '-of', 'default=nw=1:nk=1', file,
  ]).toString().trim().split('\n');
}

// Mean luminance (0-255) of a rectangle, via ffmpeg's own scaler.
function meanLuma(file, { x, y, w, h }) {
  const raw = execFileSync('ffmpeg', [
    '-v', 'error', '-i', file,
    '-vf', `crop=${w}:${h}:${x}:${y},scale=1:1:flags=area,format=gray`,
    '-f', 'rawvideo', '-',
  ]);
  return raw[0];
}

// Peak signal-to-noise ratio between two stills; higher means more similar,
// and identical images give "inf". ffmpeg writes the summary to stderr, hence
// the 2>&1 redirect. Verified on ffmpeg 7.1: identical PNGs print
// "average:inf", differing ones print e.g. "average:25.084462".
function psnr(a, b) {
  const out = execFileSync('sh', ['-c',
    `ffmpeg -v info -i "${a}" -i "${b}" -lavfi psnr -f null - 2>&1`,
  ]).toString();
  const m = out.match(/average:(inf|[0-9.]+)/);
  if (!m) throw new Error(`could not parse psnr from ffmpeg output:\n${out}`);
  return m[1] === 'inf' ? Infinity : Number(m[1]);
}

describe.skipIf(!haveFrames)('rendered frames', () => {
  it('renders one frame per loop step', () => {
    expect(existsSync(path.join(FRAMES, pad(TOTAL - 1)))).toBe(true);
    expect(existsSync(path.join(FRAMES, pad(TOTAL)))).toBe(false);
  });

  it('closes the loop exactly: frame 336 is pixel-identical to frame 0', () => {
    expect(psnr(path.join(FRAMES, pad(0)), path.join(FRAMES, 'seam.png'))).toBe(Infinity);
  });

  it('does not jerk at the seam more than a normal frame step', () => {
    const seamStep = psnr(path.join(FRAMES, pad(TOTAL - 1)), path.join(FRAMES, pad(0)));
    const normalStep = psnr(path.join(FRAMES, pad(TOTAL - 2)), path.join(FRAMES, pad(TOTAL - 1)));
    // PSNR is a similarity score, so the seam must not be markedly *less*
    // similar than an ordinary consecutive pair. 3 dB of slack.
    expect(seamStep).toBeGreaterThan(normalStep - 3);
  });

  it('keeps the copy-safe rectangle in the light luminance band, every frame', () => {
    for (let f = 0; f < TOTAL; f++) {
      const luma = meanLuma(path.join(FRAMES, pad(f)), COPY_SAFE);
      expect(luma, `frame ${f} went dark under the copy (luma ${luma})`).toBeGreaterThan(200);
    }
  }, 180_000);
});

describe.skipIf(!haveAssets)('encoded assets', () => {
  it('is 1920x1080', () => {
    expect(ffprobe(path.join(ASSETS, 'loop.webm'), 'stream=width,height')).toEqual(['1920', '1080']);
  });

  it('is 14 seconds long', () => {
    const [dur] = ffprobe(path.join(ASSETS, 'loop.webm'), 'format=duration');
    expect(Number(dur)).toBeCloseTo(14, 1);
  });

  it('carries no audio stream', () => {
    const streams = execFileSync('ffprobe', [
      '-v', 'error', '-show_entries', 'stream=codec_type',
      '-of', 'default=nw=1:nk=1', path.join(ASSETS, 'loop.webm'),
    ]).toString().trim().split('\n');
    expect(streams).not.toContain('audio');
  });

  it('fits the 4 MB budget', () => {
    const mb = statSync(path.join(ASSETS, 'loop.webm')).size / 1024 / 1024;
    expect(mb, `webm is ${mb.toFixed(2)} MB`).toBeLessThanOrEqual(4);
  });

  it('ships an mp4 fallback and a poster', () => {
    expect(existsSync(path.join(ASSETS, 'loop.mp4'))).toBe(true);
    expect(existsSync(path.join(ASSETS, 'loop-poster.webp'))).toBe(true);
  });
});
```

```python
import sys

from playwright.sync_api import sync_playwright

BASE = "http://localhost:3000/"


def check(page, label):

            ctaVisible: !!cta && cta.getBoundingClientRect().width > 0,

        };
    }""")
    print(f"[{label}] {info}")
    assert info["muted"], f"{label}: video must be muted for autoplay"
```
